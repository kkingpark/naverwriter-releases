# 밴드폰 카페 매니저 업데이트

이 저장소에는 **설치 파일과 업데이트 정보(`latest.json`)만** 있습니다. 소스 코드는 비공개 저장소에 있습니다.

- `latest.json`: 최신 버전, 설치 파일 주소, SHA-256. 빌드 PC의 개인키로 Ed25519 서명되어 있고, 프로그램은 서명과 해시가 맞을 때만 설치합니다.
- `releases/`: 버전별 설치 파일
- 설치 파일을 받아도 관리자 텔레그램 기기 승인이 없으면 프로그램을 쓸 수 없습니다.

올리는 방법: 소스 저장소의 `scripts/publish_update.py`를 씁니다. 손으로 고치면 서명이 깨집니다.
